SpendWise 💸

A modern, data-driven personal finance tracker

SpendWise is a React + TypeScript web application designed to make budgeting, tracking expenses, and saving goals feel intuitive, visual, and stress-free. The app is fully data-driven, supports dark mode, and provides interactive insights into spending behavior.

⸻

🚀 Features

🧑‍💼 Onboarding & Authentication
	•	Name-based onboarding flow
	•	Login / signup screen
	•	Logout functionality that resets the app back to onboarding

⸻

🎨 Theme & Accessibility
	•	Fully functional Dark Mode
	•	Theme toggle available across the app
	•	Theme preference persists across sessions
	•	Smooth visual transitions and accessible contrast

⸻

📂 Category Personalization
	•	Select spending categories during setup
	•	Categories are used consistently across the app
	•	Clean, chip-based selection UI

⸻

💰 Budget Management
	•	Monthly budget setup
	•	Category-wise budget allocation
	•	Budget data drives insights and predictions

⸻

📅 Spending Calendar & Analytics
	•	Interactive calendar with:
	•	Date selection
	•	Month navigation
	•	Daily spending visualized using:
	•	Color-coded indicators (low → high spend)
	•	Charts and graphs
	•	Calendar updates dynamically based on selected date/month
	•	Graceful handling of days with no data

⸻

📊 Data Visualization
	•	Graphs and charts to represent spending trends
	•	Visual insights integrated directly into the calendar view
	•	Dark mode compatible charts

⸻

🎯 Goals & Savings
	•	View existing financial goals
	•	Create new goals with:
	•	Goal name
	•	Target amount
	•	Optional deadline
	•	Goals update instantly in the UI
	•	Data-driven goal tracking

⸻

🧠 Data-Driven Architecture
	•	Centralized global state using React Context
	•	UI reacts automatically to data changes
	•	No static or hardcoded screens
	•	Easy to extend with backend APIs (Firebase / REST)

⸻

🛡 Stability & UX
	•	All existing functionality preserved during feature additions
	•	No broken navigation flows
	•	Smooth interactions without page reloads
	•	Clean and maintainable code structure

⸻

🛠 Tech Stack
	•	React
	•	TypeScript (TSX)
	•	Vite
	•	Tailwind CSS
	•	React Context + useReducer
	•	Chart libraries for data visualization
